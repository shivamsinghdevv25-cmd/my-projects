# SustainU

**Small reports. Measurable change.**

SustainU is a campus sustainability reporting prototype. Students and staff can report leaks, wasted electricity, overflowing bins, and other campus issues. Facilities staff can review reports, update their status, and award a coupon when a report is verified as resolved.

The campus map is an illustrative, clickable layout. Selecting a building shows example spaces and lets you start a report with that building preselected. Reports ask for a room, floor, or nearest room, plus an optional nearby landmark.

The prototype also includes a campus exchange for listing and browsing second-hand items, plus a weekly good-deeds leaderboard. Posting a report earns 3 demo points; listing an item earns 2. Points for the current browser profile reset on Monday, and the top three on the sample board are shown with weekly goodies.

## Run it

Open `index.html` in a web browser. No installation or server is needed.

This is a front-end demo. The campus map is not a surveyed or navigable real map. Reports, listings, interest buttons, and points are saved in the browser with `localStorage`; they are not shared with other devices or sent to real facilities staff or sellers. The leaderboard names and scores are sample data, and the goodies are illustrative. Use the **Staff view** switch to try resolving a report and issuing a reward.
